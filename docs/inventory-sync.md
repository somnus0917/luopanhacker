# 库存同步运行说明

同步程序只允许调用已配置的标准只读查询接口，并在服务器本地生成快照。网页不会调用旺店通，也不会写入库存。

## 两种运行方式

- 日结快照（每天一次）：`./scripts/run_inventory_sync.sh`
  - 写入最新快照与 `output/inventory/history/YYYY-MM-DD.json`。
  - 同一天已存在的历史文件不会被覆盖。
- 日内刷新（按需）：`./scripts/run_inventory_sync.sh --refresh-only`
  - 只更新最新快照，不影响日结历史。

建议将日结任务安排在每日 02:30–03:30；日内刷新可安排在 09:00、13:00、17:00。请由服务器的任务调度器运行，并通过环境变量或密钥管理服务提供旺店通访问凭据；不要把密钥写进脚本、任务参数或仓库。

## 数据保护

- 进程锁阻止并发同步；超过三小时且原进程已不存在的锁会自动恢复。
- 所有 JSON 文件采用临时文件加原子替换，读取端不会看到半份文件。
- 所有接口数据完成、增量库存合并完成且校验通过后，才替换最新快照。
- 失败时保留上一份成功快照，并将失败时间与原因写入 `output/inventory/sync_state.json`。
- 仅累计 30 份连续日结快照后，页面才会显示 30 天实际周转；此前只显示近期出库推算的预计可售天数。
